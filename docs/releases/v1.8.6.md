# 喆好工具箱 v1.8.6

## 本次更新

- 更新检查通过 GitHub 的公开签名清单下载地址获取最新版本，避免共享 IP 的匿名 REST API 限流。
- 更新说明一并加入签名清单，程序可直接显示已校验的版本说明。
- 关于页仅保留软件简介与版本号，界面及图标使用“喆好工具箱”品牌。
- 发现新版后自动下载，下载完成后可重启安装；继续保留签名、文件长度、SHA-256 校验及更新事务和回滚流程。
- 运行时、功能模块、更新模块与 PBO 路径修复均内置于单文件 EXE。

## 下载与使用

下载附件 `Zhehao.Toolkit.v1.8.6.exe` 即可运行，可改名为 `喆好工具箱.exe`。支持 Windows 10 / 11 x64，按程序提示授予管理员权限。

先从托盘正常退出旧版，再启动新版。保持设置中的“自动检查更新”开启，后续版本会从本仓库自动下载；下载完成后点击“重启更新”。无需配置 GitHub 账号或 Token，在线更新需要能够访问 GitHub。

程序会自动读取 `zhehao-update.json`；普通使用只需下载 EXE。`SHA256SUMS.txt` 供手动核对下载文件。
